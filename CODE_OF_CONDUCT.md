# Code of Conduct

## The short version

Be kind, specific, and constructive. This is a small open-source project for
people making video; everyone should be able to participate without being put
down, harassed, or talked over.

## Expected behaviour

- Assume good intent and give useful, technical feedback.
- Critique code, decisions, and output—not people.
- Respect differing experience levels, workflows, identities, and hardware.
- Keep issue threads focused enough that someone can act on them.

## Not okay

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or unwanted attention.
- Publishing someone else's private information.
- Repeatedly derailing a discussion after being asked to stop.

## How moderation works

The maintainer may edit, hide, or remove contributions that violate these
guidelines, and may limit participation where necessary. If something needs
attention, open a minimal GitHub issue asking the maintainer to review it—do
not repost private material or escalate the situation in public.

This code applies to project spaces and to public interactions that clearly
represent the project.
