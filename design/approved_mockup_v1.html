What changed from today's build

  • 10 toolbar buttons → 3 (Add split-button, Settings, ⋯More)
  • Scopes / banding / remove moved to per-row hover actions — no more "select a file first"
  • Format / Deband / Bitrate tucked in a collapsible "Adjust" row, closed by default
  • Convert is the only always-visible action; Stop/Cancel appear only while running, in its place
  • Emoji replaced with one consistent line-icon set
  • New: teaching empty state (State 0) — shows what the tool does before you've added anything
  • New: quick-look hover preview on Done rows — before/after thumbnail, no modal (State 1)
  • New: named phase pill ("Encoding") on the running row + Now-running panel, not just a %
  • New: inline dismissible batch-summary banner when a run finishes (State 3) — no more hunting for "Last report"

Kept as-is

  • Presets front-and-center (Delivery / Grading / Max preservation + custom)
  • Drag handle + reorder on every row
  • Live per-file % and the batch "Now running" panel
  • Verify info (✓ 10-bit · Mbps · size) on completed rows
  • Same accent blue, same dark/light theming approach
  • Full granular control stays one click away — the ⚙ Settings modal keeps every power-user option (CRF, dither, deband range, denoise, two-pass, audio, custom bitrate, dest folder…) exactly as today. The toolbar decluttered; nothing was removed.
